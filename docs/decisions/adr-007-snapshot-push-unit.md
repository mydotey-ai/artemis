# ADR-007：推送单元 = service 实例集快照

版本: 1.0    更新时间: 2026-10-10

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

SDK 订阅推送需要明确的交付语义。原产品推送单元即 service 实例集快照（能力基线 §5 资产），重设计将传输升级为 gRPC server-streaming。

## 决策

推送单元为 service 实例集快照：原子、幂等覆盖（后到快照整体替换消费方本地状态）；gRPC server-streaming 单流内天然有序。

## 理由

原子、幂等覆盖、消费方无需增量拼接。

## 否决方案

实例级 delta 推送——拼接复杂，乱序难处理。

## 后果

- 乱序/丢失窗口由三层兜底轮询收敛（订阅推送失败或空服务 60s 主动拉、15min 全量刷新）——at-most-once 推送的自愈底线。
- SDK 回调直接持有快照引用（零深克隆，修复原产品局限 #13 的深克隆部分）。
