# ADR-010：namespace 进 v0.1 数据模型

版本: 1.0    更新时间: 2026-10-10

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

多环境/多租户聚合是产品生态位（行业对标报告 §5.3）；namespace 是行业基线能力（Nacos/Consul 均有）。proto 数据模型一旦发布，后加字段涉及存量数据语义迁移。

## 决策

namespace 字段进入 v0.1 的 proto 公共数据模型（`common.v1`）。

## 理由

行业基线、多租户地基，后加迁移代价大。

## 否决方案

后加字段——发布后再补 namespace 需处理存量注册数据的归属语义与 SDK 兼容。

## 后果

- discovery 投影/查询按 `(cluster, namespace, service, group)` 组织。
- v0.1 即支持按 namespace 的选择器过滤（聚合语义本地合并）。
