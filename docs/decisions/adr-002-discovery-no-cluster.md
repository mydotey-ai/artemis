# ADR-002：discovery 不组集群

版本: 1.1    更新时间: 2026-10-24

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

discovery 承担只读投影与多集群聚合。若组对等集群，需要跨源（多 registry 集群）合并的集群协议，且 Rust 混合集群（ADR-008）的互通面随之扩大。

## 决策

discovery 节点是独立投影副本，实例间零协议：任一节点故障由消费方 SDK 地址容灾消化；多集群聚合 = 单节点订阅多个 registry 集群后本地合并。

## 理由

- 多源聚合语义只在本机发生，无跨源污染。
- 集群协议只剩 registry 复制一条，Rust 互通面最小（配合 ADR-008）。

## 否决方案

discovery 对等集群——多源合并语义复杂化。

## 后果

- discovery 无集群状态、无节点间协议；**不提供存活节点列表**（无探测）。SDK 以 HTTP 引导地址 → **静态节点目录**（v0.3 phase-8，[ADR-020](adr-020-discovery-static-node-directory.md)）→ 历史成功连接缓存 + 熔断换址容灾——节点目录是部署声明，不是存活探测。
- 新节点冷启动独立 bootstrap（全量覆盖幂等即自愈）。
