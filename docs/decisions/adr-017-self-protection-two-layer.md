# ADR-017：自我保护 2.0——节点级兜底 + 服务级双层保护

版本: 1.1    更新时间: 2026-10-21

## 状态

Accepted（2026-10-21，v0.2 phase-4 设计 review 中用户定案）

## 背景

原产品与 v0.1 均采用**全局单阈值**：10s 滑动窗口统计续约量，历史峰值 ≥ 50 时，当前窗口低于峰值 85% 进入保护态，跳过全部「仅过期」清理（[架构](../arch/artemis-next-architecture.md) §4.1、[基线](../legacy/legacy-product-analysis.md) §6 #9）。该模型有两个缺口：

- **无法区分局部异常与网络故障**：单个服务续约骤降不会触发保护，局部故障被当成真实下线批量摘除；
- **纯按服务粒度并非简单替换**：历史峰值只增不减时，某服务的客户端迁到其他节点后，本节点续约归零而峰值仍在，该服务及其副本会**永久保护**；同时小服务（峰值 < `minCount`）在节点级网络分区中会失去兜底。

保护态本身也缺少显式状态与有界可观测性：只有布尔值，无迁移、时长与按服务指标；若给每个服务常驻 3 个 gauge，稳态基数 = 3 × 服务数，不可运维。

## 决策

1. **双层判定**：保留节点级全局窗口（沿用 v0.1 算法）作为网络分区/小服务/纯副本兜底；新增每服务窗口。服务窗口历史峰值达到 `minCount` 后服务级状态权威；未达门槛或无本地窗口时回落节点级状态。
2. **显式状态机**：每窗口维护 `NORMAL/PROTECTING`、`protectingSince`、迁移计数与结构化日志；状态只由周期评估器（复用 1s 清理调度）写入，查询/抓取只读。
3. **基线回落限制误保护**：节点级健康时，服务窗口 `maxCount` 连续 `maxCountResetMs`（默认 10min）未抬升即回落到当前窗口续约量（通常退出保护）；节点级保护中不回落。节点级窗口沿用原产品安全态回落语义。
4. **有界指标**：节点级保留 v0.1 三个 gauge；服务级 `service.protection{namespace,service}` 仅在 PROTECTING 期间注册，另有保护中服务数 gauge 与状态迁移 counter。服务级 renewals/max 明细走 API。
5. **独立查询 API**：`management.v1.GetSelfProtectionStatus`（registry 实现、management 透传）默认只返回保护中服务，支持 namespace/service 过滤、10000 条上限与 truncated，并返回节点级统计；指定 namespace+service 时该服务总是返回。服务条目同时给出服务级 `protecting` 与 `node_fallback`（服务级未启用、清理判定取节点级），避免节点级兜底中的小服务被误读为未保护；`GetLeaseStatus` 保持节点级语义不变。
6. **节点独立**：保护态不复制、不持久化，各节点只按本地收到的心跳独立判定；保护态不抑制复制（仅跳过本地过期清理）。

## 理由

- 节点级层保留原产品「大面积失联不批量误摘」的核心承诺，并覆盖小服务/副本；服务级层修复局限 #9，局部异常只影响局部。
- 超时回落把「单服务客户端迁移」导致的陈旧数据上界压到 `maxCountResetMs + TTL`，同时用节点级信号避免在真实网络分区中提前回落。
- 显式状态与唯一写入口消除查询副作用、指标注册竞态与状态漂移；按保护态注册 gauge 使指标基数与故障规模而非服务总数相关。
- 独立 API 避免把旧 `protection` 字段硬凑成无阈值语义的聚合，也避免全量服务列表撑爆响应。

## 否决方案

- **纯按服务、无节点级兜底**：小服务与副本在节点级分区中失去保护，且全局故障时逐服务判定成本高、语义不完整。
- **纯按服务、不自动回落**：客户端迁移造成永久保护与陈旧副本，须人工干预，按服务粒度下误报概率远高于全局。
- **每服务常驻 renewals/max/protection 三个 gauge**：稳态 3 × 服务数 series，Prometheus 基数不可控。
- **扩展 `GetLeaseStatus` 返回按服务列表**：旧 `protection` 字段的聚合语义无法自洽，默认全量列表无响应上限。
- **保护态复制/持久化**：各节点网络视角不同，保护态是本地观测而非全局事实；引入复制会带来一致性与陈旧状态传播问题。

## 后果

- 节点健康时，单服务误保护最多保留约 `maxCountResetMs + TTL` 的陈旧租约；节点级长分区仍可能保留陈旧数据（原产品取舍），但保护态经指标/API 显式可观测。
- 周期评估成本 O(服务数 × 窗口桶数)/秒；10k 服务 × 10 桶 ≈ 10 万桶求和/秒。
- 服务级 `minCount` 沿用全局键：峰值低于门槛的小服务只在节点级故障时受保护（与原产品全局门槛一致）。
- 对外节点状态 API（`replication.v1.NodeStatusService`）不承载保护态；保护态查询走 management 状态 API。
