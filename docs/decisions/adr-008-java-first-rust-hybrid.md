# ADR-008：Java 25 + Spring Boot 4.1 先行，Rust 后补混合集群

版本: 1.0    更新时间: 2026-10-10

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

服务端计划 Java 与 Rust 双实现：Java 是作者主场（先出活），Rust 在数据面有性能/资源优势。跨语言互通的前提是 proto 契约稳定；契约反复变更下第二实现会被反复拖拽。

## 决策

Java 25 + Spring Boot 4.1 先行实现全部三服务；Rust 后补 registry 数据面，同一集群可混布 Java/Rust 节点；数据面 proto 经 v0.2–v1.0 稳定后冻结，Rust 实现只做一次。

## 理由

- 作者主场先出活。
- 契约冻结后 Rust 只做一次（不被契约演进反复拖拽）。

## 否决方案

直接双语言起步——契约未稳定时双端同步成本翻倍。

## 后果

- 混合集群互通面只需数据面协议（心跳/复制/分发/成员 proto）；management/discovery 无集群协议，Rust 无需实现（ADR-002 使互通面最小）。
- 内核零 Spring 的模块边界（enforcer 硬约束）同时为 Rust 对照实现划出清晰内核范围。
