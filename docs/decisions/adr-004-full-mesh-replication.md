# ADR-004：全对全 + 增量报文，负责制后置

版本: 1.0    更新时间: 2026-10-10

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

心跳即注册语义下，写到达节点随机（事实权随连接节点）；Nacos Distro 负责制是行业成熟方案。目标集群规模 ≤10 节点起步（20+ 为远期）。

## 决策

registry 集群采用全对全异步复制 + 增量小报文扇出（心跳 diff 出变更才扇出，稳态零复制流量）；负责制分片后置为 v1.x 规模选项（20+ 节点）。

## 理由

- 心跳即注册下写到达节点随机，负责制需转发一跳。
- ≤10 节点增量扇出无压力。

## 否决方案

Distro 负责制先行——作为 v1.x 规模选项预留，不先行。

## 后果

- 节点规模上界约定由全对全扇出成本决定（规模选项已预留）。
- 变更事件批量异步投递 + 失败定向重试（指数退避 + 抖动）。
