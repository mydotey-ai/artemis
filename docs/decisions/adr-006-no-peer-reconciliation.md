# ADR-006：peer 间无拉对账

版本: 1.0    更新时间: 2026-10-10

## 状态

Accepted（2026-10-10，架构设计定稿）

## 背景

分布式注册表常见防御性设计是 peer 间定期 hash 比对 + 差异拉全量对账。原产品未做对账而靠自愈链保持一致。

## 决策

registry peer 之间不做任何拉对账；registry 定期任务只有租约过期清理与快照落盘两个。

## 理由

心跳周期全量上报（幂等）+ 客户端连接 TTL 轮换 = 分布式对账：客户端换到任意节点，全量心跳上报即修复该节点。

## 否决方案

定期 hash 比对拉全量——多余（自愈链已覆盖丢失场景）。

## 后果

- 事件丢失的恢复路径固定为三条：变更再扇出、客户端 TTL 轮换、新 peer bootstrap。
- 无对账周期任务的稳态开销。
